# 📊 AdventureWorks Sales Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Power BI Sales Dashboard** built using the **AdventureWorks** dataset. The dashboard provides comprehensive insights into sales performance, customer behavior, product performance, and regional trends, enabling data-driven business decisions.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- SQL
- AdventureWorks Dataset

---

## 📂 Dataset

The project uses the **AdventureWorks** sample dataset, which contains information related to:

- Sales Orders
- Customers
- Products
- Product Categories & Subcategories
- Sales Territories
- Salespersons

---

## 📊 Dashboard Features

### 📈 Executive Summary
- Total Revenue
- Total Orders
- Total Customers
- Quantity Sold

### 💰 Sales Analysis
- Revenue by Category
- Revenue by Subcategory
- Monthly Sales Trend
- Quarterly Sales Analysis
- Top Performing Products

### 👥 Customer Analysis
- Customer Distribution
- New vs Returning Customers
- Top 10 Customers
- Customer Revenue Contribution

### 📦 Product Analysis
- Best Selling Products
- Product Performance by Category
- Revenue Contribution

### 🌍 Territory Analysis
- Revenue by Territory
- Sales Distribution
- Territory Performance Comparison

---

## 📈 Key Insights

- North America generated the highest sales revenue.
- Bikes contributed the largest share of total revenue.
- A small percentage of customers generated a significant portion of overall sales.
- Sales showed clear seasonal trends across different quarters.
- Product and territory analysis highlighted high-performing business segments.
